五、软件功能和技术特点

硬件环境 开发机：个人笔记本电脑，Intel 酷睿 i7 及以上，内存 ≥8GB，硬盘 ≥100GB 可用
运行环境：Android 7.0（API 24）及以上手机，带摄像头闪光灯、扬声器
软件环境 开发环境：Windows 10/11 或 macOS / Linux，VS Code 编辑器，Node.js 18+（仅用于打包）
运行系统：Android 原生（通过 Capacitor 打包为 APK），无任何后端依赖、无网络要求
编程语言 HTML5、CSS3、JavaScript ES2022（纯原生，无任何框架依赖）
源程序量（行数） 约 2500 行（含 HTML / CSS / JS / manifest / Service Worker 全部核心文件）
主要功能和技术特点 开发目的：面向演唱会应援、车辆故障临时警示、户外活动标识等场景的移动端荧光字牌工具。
面向领域：文化娱乐（演唱会应援）、交通应急（车辆故障警示）、个人安全（夜间信号）。
主要功能： ① 自定义发光文字：5 种字体，字号自动适配屏幕； ② 文字特效：霓虹发光、闪光、跳动、走马灯、彩虹渐变可自由组合； ③ 背景频闪：整屏 0.5–12Hz 频闪 / 三格警灯模式（红-琥珀-白依次点亮，独立描边光晕）； ④ 摄像头闪光灯频闪（0.5–20Hz 可调）； ⑤ 4 种民用高频警示音（避开警用频率，2000–4000Hz 安全频段）； ⑥ 演出模式：一键全屏、屏幕常亮、横屏自适应。
技术特点： ① 纯前端实现，零后端依赖，纯本地运行； ② APK 仅 1.1MB，运行时内存 <50MB； ③ CSS 状态机驱动三格警灯，60fps 无性能损耗； ④ Web Audio API 合成警示音，DynamicsCompressor 防破音； ⑤ Service Worker 离线缓存，飞行模式可运行； ⑥ vmin 自适应布局，不同屏幕尺寸自动适配。
