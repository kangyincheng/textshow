## 二、可直接粘贴的文本模板

### 2.1 软件简介（推荐150–200字）
```
闪闪发光 是一款面向演唱会应援、车辆故障临时警示、户外活动标识等场景的移动端荧光字牌工具。
用户可自定义屏幕显示的文字内容，支持 5 种字体、霓虹发光、走马灯、跳动、彩虹渐变等多种文字特效，
以及整屏频闪、三格警灯式警示模式等背景效果。
支持 Android 摄像头闪光灯同步频闪（0.5–20Hz 可调），
内置 4 种合规高频警示音（3000Hz 民用频段），
演出模式下自动全屏、屏幕常亮，无需任何后端服务依赖，纯本地运行。
```

### 2.2 主要功能
```
1. 自定义发光文字：支持任意文字输入，5种字体选择，字号 6–40vmin 滑杆调节，长文本自动适配
2. 文字特效：霓虹发光、文字闪光、跳动动画、走马灯、彩虹渐变，可自由组合
3. 背景效果：整屏频闪（0.5–12Hz 可调）、三格警灯警示模式（红/琥珀/白依次点亮，独立描边光晕）
4. 摄像头闪光灯频闪（0.5–20Hz 可调，Android 原生支持）
5. 警示音：4种模式（急促哔声/警笛扫频/持续鸣响/高频警报），基于 Web Audio API 合成，音量可调
6. 演出模式：一键全屏 + 屏幕常亮 + 横屏自适应
7. 预设方案：演唱会/车辆故障/纯净字幕三种一键切换
```

### 2.3 技术特点
```
1. 纯前端实现，零后端依赖：基于 HTML5 + CSS3 + JavaScript ES2022 原生开发，无任何框架或第三方 SDK 依赖，APK 仅 1099KB
2. Capacitor 原生打包：把纯前端代码封装为 Android 原生 APK，仅桥接摄像头闪光灯、音频、Wake Lock 三项硬件权限
3. 三格警灯 CSS 状态机：JS 仅负责推 DOM 属性，亮/暗态渲染全由 CSS 属性选择器完成，60fps 零性能损耗
4. Web Audio 警示音引擎：DynamicsCompressorNode 防止高频破音，频率避开警用专用频段，采用 2000–4000Hz 民用安全范围
5. Service Worker 离线缓存：首次加载后自动缓存全部资源，飞行模式可运行
6. vmin 自适应布局：字号、间距、动画全部使用 vmin 单位，竖屏/横屏/不同屏幕尺寸自动适配
```

## 四、排版技巧（一次性过审）

1. **源代码排版**：
   - 每页恰好 50 行（不足50行的页也算1页）
   - 第一页顶部留空写页眉：`闪闪发光 APP V1.0` + 页脚页码
   - 最后一页如果不足50行，正常提交即可，不需要凑

2. **说明书排版**：
   - 页眉统一：`闪闪发光 APP V1.0`
   - 目录页算第1页，按目录→概述→功能→技术→附录的顺序
   - 每页 ≥30 行（图片可以占行，但尽量多写文字）

3. **避免被打回的细节**：
   - 软件全称必须带「软件」或「APP」，不能只叫「闪闪发光」
   - 开发完成日期必须晚于著作权人成立/出生日期
   - 所有提交的电子件分辨率 ≥300dpi，清晰不模糊
