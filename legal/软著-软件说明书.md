## 一、软件概述

### 1.1 软件名称
TEXTSHOW 荧光字牌 APP（简称 TEXTSHOW）

### 1.2 软件版本
V1.0

### 1.3 开发目的
TEXTSHOW 是一款面向演唱会应援、车辆故障临时警示等场景的**移动端荧光字牌工具**。用户可将手机屏幕转化为高亮度、高可见度的动态发光牌，用于：
- **演唱会应援**：自定义文字、字体、颜色、动画效果，支持走马灯、闪光、跳动等动态效果，屏幕常亮、扬声器可播放警示音
- **车辆故障警示**：三格警灯式频闪 + 摄像头闪光灯同步频闪 + 尖锐警示音，符合民用安全标准
- **户外活动标识**：自定义发光文字，夜晚醒目

### 1.4 适用场景
演唱会、音乐节、户外露营、车辆故障、应急疏散标识、商业促销展示

### 3.2 核心功能详细说明

#### 功能1：自定义发光文字
- 操作：主界面「01 文字内容」区域，直接输入框编辑文字
- 支持最多一行完整显示（超长自动缩小字号，提示「40→21.2」表示原字号40vmin，自动适配后为21.2vmin）
- 字号滑杆范围：6–40vmin（相对于屏幕短边百分比）

#### 功能2：文字发光特效
- **霓虹发光**：多层 text-shadow + 外溢 box-shadow，颜色自定义
- **文字闪光**：独立频闪开关，频率跟随背景频闪设置
- **跳动动画**：CSS keyframes bounce，动画速度可调 0.3–3×
- **走马灯**：水平循环滚动，左右边缘渐隐过渡，自动隐藏屏幕边缘
- **彩虹渐变**：linear-gradient 多色扫过，加 -webkit-text-stroke 增强可读性

#### 功能3：背景频闪
- **整屏频闪**：0.5–12Hz 滑杆调频，整屏在背景色与闪光色间切变
- **三格警示模式**：三等分三色（红/琥珀/白），每格配独立描边（红→琥珀、琥珀→白、白→品红），按「红亮→空→琥珀亮→空→白亮→空→循环」时序，约 1.08Hz，独立外溢光晕层次
- 与走马灯等特效不冲突，可叠加

#### 功能4：摄像头闪光灯频闪
- 0.5–20Hz 滑杆调频（比屏幕频闪范围更大，适应不同警示需求）
- Android Chrome/Edge 原生支持：调用 `MediaDevices.getUserMedia` + `torch` 约束
- 自动请求相机权限，权限拒绝时提示「您的设备不支持网页控制闪光灯」

#### 功能5：警示音
- 基于 Web Audio API 实现，4 种模式：
  1. **急促哔声**：3100Hz 方波，0.07s 鸣 + 0.08s 歇（紧急警示）
  2. **警笛扫频**：750Hz ↔ 1750Hz 三角波指数扫频，0.62s 周期
  3. **持续鸣响**：2350Hz 方波 + 6Hz LFO 调制（类似烟雾报警器）
  4. **高频警报**：2600Hz 方波，0.16s 鸣 + 0.26s 歇
- 音量 0–100% 可调，带 DynamicsCompressorNode 防止破音失真
- 「合规尖锐」：避开警用专用频率（700–850Hz），采用 2000–4000Hz 民用安全频段

#### 功能6：演出模式
- 一键进入：关闭控制面板 → 全屏 → 请求 Wake Lock（防止熄屏）→ toast 提示「演出模式 · 轻触屏幕打开控制」
- 轻触屏幕任意位置可重新打开控制面板

### 3.3 操作指南

#### 3.3.1 基础使用流程（演唱会应援场景）
1. 打开 APP，底部面板默认展开
2. 「01 文字内容」输入粉丝团口号，选字体为「冲击黑」，字号调大到 35
3. 「02 文字特效」开启「霓虹发光」+「走马灯」+「跳动」
4. 「03 背景闪光」开启「背景频闪」，频率滑到 4Hz
5. 「04 摄像头闪光灯」开启，频率 8Hz
6. 「05 警示音」开启声音（怕吵可以不开）
7. 点「开始演出」→ 手机横举 → 屏幕自动横屏，常亮

#### 3.3.2 车辆故障警示场景
1. 打开 APP，面板展开
2. 输入「车辆故障 请绕行」，选默认字体
3. 「03 背景闪光」开启「三格警示模式」（自动关闭整屏频闪）
4. 「04 摄像头闪光灯」开启，频率建议 6Hz
5. 「05 警示音」开「急促哔声」，音量 70%
6. 点「开始演出」→ 三角警示牌 + 闪光灯 + 警示音同步工作

## 四、技术特点与实现架构

### 4.1 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | HTML5 + CSS3 + JavaScript ES2022 | 无任何框架依赖，纯原生 |
| 打包 | Capacitor 6.x | 把纯前端代码打包为 Android 原生 APK，无 WebView 壳额外逻辑 |
| 原生桥接 | Capacitor Core | 仅用于 WebView ↔ 原生权限请求（闪光灯、音频、Wake Lock） |
| 离线缓存 | Service Worker | 首次加载后自动缓存所有资源，断网可运行 |

### 4.2 核心技术实现

#### 4.2.1 三格警灯状态机
```
seq = [0, 3, 1, 3, 2, 3]  # 0=红亮、3=gap全灭、1=琥珀亮、2=白亮
每 240ms 推进一步 → 完整周期约 930ms → 1.08Hz
```
- 纯 CSS `[data-strip="N"]` 属性选择器驱动亮/暗态
- JS 状态机只负责推属性，UI 渲染全由 CSS 完成（60fps，无性能损耗）
- 亮态 box-shadow 双层外溢：描边层 30px + 主体层 70px，颜色独立控制

#### 4.2.2 摄像头闪光灯控制
```
const stream = await navigator.mediaDevices.getUserMedia({ video: { advanced: [{ torch: true }] } })
const track = stream.getVideoTracks()[0]
// 频闪：每 halfPeriod 切换 applyConstraints({ torch: true/false })
```
- 半周期 `halfPeriod = max(20, 500 / hz)`（最低 20ms 保证硬件响应时间）
- 页面隐藏（visibilitychange）时自动关闭闪光灯，防止意外闪盲

#### 4.2.3 Web Audio 警示音引擎
```
class SoundEngine {
  constructor() {
    this.ctx = new AudioContext()
    this.compressor = this.ctx.createDynamicsCompressor()
    this.master = this.ctx.createGain()
    // compressor → master → destination
  }
  startBeeps(urgent) {
    this.osc = this.ctx.createOscillator()
    this.filter = this.ctx.createBiquadFilter()  // lowpass 防止高频破音
    // urgent: 3100Hz / 0.07s on / 0.08s off
    // steady: 2350Hz + 6Hz LFO modulation
  }
}
```

#### 4.2.4 文字自动适配（长文本防裁切）
```
function fitStageText() {
  fittedFontSize = state.fontSize
  stage.style.setProperty('--font-size', `${state.fontSize}vmin`)
  for (let i = 0; i < 4; i += 1) {  // 最多迭代4次
    const ratio = Math.min(availableWidth / scrollWidth, availableHeight / scrollHeight)
    if (ratio > 0.995) break
    fittedFontSize = fittedFontSize * Math.max(0.3, ratio) * 0.985
    stage.style.setProperty('--font-size', `${fittedFontSize}vmin`)
  }
}
```

### 4.3 架构优势
1. **零后端依赖**：纯本地运行，无服务器、无 API、无数据收集，隐私友好
2. **低内存占用**：APK 仅 1099KB（R8 混淆后），运行时内存 <50MB
3. **响应式 UI**：vmin 单位 + JS 迭代适配，竖屏/横屏/小屏自适应
4. **高性能**：CSS 动画（硬件加速）+ CSS 变量（GPU 渲染），状态机推属性，JS 主循环占 CPU <5%
5. **可离线**：Service Worker 预缓存，飞行模式可运行
